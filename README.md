A personal collection of prompts I have refined across 200+ annotation, evaluation, and AI training tasks. They are intentionally short: the useful part is the repeatable review habit around each prompt, not elaborate prompt decoration.

## How I use this collection

I start with the smallest prompt that matches the task, add the project rubric, and review the output against evidence. Prompts are starting points rather than magic formulas; clear instructions and careful human review still matter most.

## Tech stack

Markdown, Git, and practical experience from data annotation and LLM evaluation workflows.
